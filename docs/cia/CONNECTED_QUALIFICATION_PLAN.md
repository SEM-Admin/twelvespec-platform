## Next schema/qualification contracts (before implementation)

- Orders/production owns immutable `process_profile_versions`, with scoped product/variant/source references, captured revisions, explicit producer/facility/substrate/method/zone, documented dimensions and output-contract reference. A documented planning profile never grants manufacturing release. Missing geometry/profile facts remain unknown; no universal embroidery/DPI/bleed parameters.
- Extend existing price observations with component role and charging basis (`PER_ITEM`, `PER_ORDER`, `PER_SHIPMENT`) and optional exact process-profile/method/location. Preserve M1 material/per-item defaults and fingerprint compatibility. Setup is not disguised as a pack of caps. Nonmaterial charges need exact method/profile applicability. All eight existing Pricing components require actual evidence, including any explicit zero.
- Keep supplier account identity distinct from customer-account restrictions. M1's optional CRM account restriction is not a supplier-login entitlement. Unmapped native account tariffs remain blocked; no license/account eligibility is invented.
- A qualification reads the authoritative draft line and complete current evidence, records a private immutable explanation, and changes no quote/order/PO/payment/publication/production state. Missing availability, destination, dates, rights, costs or exact identity block complete qualification. Do not invent business-day calendars; retain a source-confirmed delivery date.
- A wholly synthetic scenario can demonstrate complete arithmetic and route checks, but always returns false for real quote-cost/production authorization. Mixed synthetic/real evidence must not promote the synthetic part into a real decision.
- Applying a real qualified proposal to the existing reviewed cost worksheet still requires the operator's commercial review and margin/issue gates. Any future committing consumer must recheck current source rights, exact configuration and cost evidence; cached decisions remain historical.
- Required technical production checks, physical tests and manufacturer acceptance remain independent holds. A quote review can state conditional artwork scope without claiming that an illustrative proof is a production file. CAD/digitizing/3D activation is excluded.
