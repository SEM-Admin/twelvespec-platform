## Test isolation

The complete browser suite now creates and drops only a disposable local database. It refuses to reuse occupied application ports, so a running development preview cannot silently receive browser test writes. Focused `npx playwright test` remains available for explicit synthetic preview debugging.

## Remaining activation gates

Real SAGE keys/fee schedule, SinaLite live API credentials, licensed data/image rights, persistent hosted database/artwork/credential storage and recovery, production payments/tax/shipping, real order submission, dependable scheduled publishing, unsupported video/download processing, and production deployment remain separate gates. Synthetic workflows and a public SinaLite sandbox read are not proof of live business readiness.
