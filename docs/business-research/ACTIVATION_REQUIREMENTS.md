# What can be built now and what needs later access

No credentials or approvals are requested by this research packet. Most workflow logic can be built and tested with synthetic data now. Request account material only when a specific integration is ready for authorized testing.

| ID | Area | Current evidence/status | Needed next | Approval boundary |
| --- | --- | --- | --- | --- |
| R-01 | Core feature development | CAN_IMPLEMENT_WITH_SYNTHETIC_DATA | Implement the original designs, regression tests and complete UI paths in the existing repository. | Routine engineering; no vendor account required. |
| R-02 | Persistent development database | EXISTING_BLOCKER_RECORDED | Approved development connection needs its trusted certificate chain; current preview demo database is temporary. | Credential/certificate material through the approved secure channel; no production connection. |
| R-03 | Private assets and secrets | FOUNDATION_IMPLEMENTATION_OPEN | Durable private artwork and managed secret broker with verified recovery. | Any new paid service or account infrastructure change requires approval. |
| R-04 | Direct supplier/POD adapters | PUBLIC_BEHAVIOR_RESEARCHED_NOT_INTEGRATION_VERIFIED | Authorized current schemas, sandbox access, scoped credentials, account pricing, permitted media and operation-level tests. | Credentials, licensing and any financial commitment when ready for account testing. |
| R-05 | ASI SmartLink and ESP interfaces | LICENSED_CONTRACT_REQUIRED | Keep interfaces separate; obtain official entitled schemas, media/redistribution rights and developer credentials. | Licensing and credentials; PSRESTful is prohibited. |

No existing production TwelveSpec system, supplier account, payment processor or customer dataset was accessed or changed for this research.
