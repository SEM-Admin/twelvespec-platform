Always follow catalog eligibility

  • Published canonical products and exact variants.
  • Stable ordering and visible/hidden scope.
  • Categories, brands, industries, occasions and solutions.
  • Paused products cannot return through an old page release.
  • No wholesale cost, supplier credentials or private source payload.

Validation checklist · proposed behavior

  • Current site and actor permissions.
  • Supported sections, safe links and required fields.
  • Current product eligibility and media usage rights.
  • Consistent page, header, footer and brand revisions.
These are planned checks, not validations executed by this prototype. Real publication needs the Phase 1–2 backend.

When should it go live?

Scheduling requires durable jobs and reliable executor waking. The current idle-stopped preview cannot yet guarantee it. Ambiguous times must be resolved explicitly.

Rollback is a new audited release

A page restore preserves unrelated changes. A whole-site rollback is a distinct owner action. Current media rights and product eligibility are checked again.

Quotes, orders, payments and production records are never rolled back by a website action.
