## Evidence labels
`DOCUMENTED_BY_VENDOR` = public vendor specs reviewed; `OBSERVED_IN_DEMO` = UI interaction observed; `DESIGN_PROPOSAL` = our independent requirements; `IMPLEMENTED_IN_LAB` = isolated local prototype verified by tests; `SANDBOX_VERIFIED` = authenticated third-party sandbox response actually observed; `LIVE_VERIFIED` = independently reviewed real environment behavior. Never promote evidence label without new test artifacts.

## Important limits
No legitimate third-party vendor source proves universal access to all supplier endpoints, correct all-product decoration rules, zero-code support for undocumented proprietary API protocols, or production-ready art generated by simple path tracing. These remain explicit adapter, entitlement and preflight gates.
